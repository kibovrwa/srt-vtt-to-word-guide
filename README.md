# Turn SRT / VTT subtitles into Word

Editors still get stuck pasting subtitle files into docs. [SRT2Word](https://srt2word.com) converts SRT, VTT, ASS and CapCut exports into an editable `.docx` in the browser.

## Common jobs

| Need | Tool |
| --- | --- |
| SRT → Word | [srt2word.com](https://srt2word.com) |
| Batch SRT | [Batch SRT to Word](https://srt2word.com/batch-srt-to-word) |
| ASS → Word | [ASS to Word](https://srt2word.com/ass-to-word) · [ASS to SRT](https://srt2word.com/ass-to-srt) |
| CapCut | [CapCut subtitles to Word](https://srt2word.com/capcut-subtitles-to-word) |
| Bilingual columns | [Bilingual subtitle columns](https://srt2word.com/bilingual-subtitle-columns) · [Bilingual to Word](https://srt2word.com/bilingual-subtitles-to-word) |

## Quick steps

1. Export or download the subtitle file (`.srt` / `.vtt` / `.ass`).
2. Open the matching tool above and upload.
3. Download the `.docx` and edit timings/text in Word or Google Docs.
